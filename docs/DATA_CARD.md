# Data Card — ThreatSense Synthetic Flow Capture

| Field | Value |
|---|---|
| **Type** | Synthetic network-flow metadata (no payloads, no real IPs) |
| **Generator** | `src/threatsense/ingestion/synthetic.py` (deterministic per seed) |
| **Size** | ≈51 000 flows over 48 simulated hours, ≈18 % malicious |
| **Unit of analysis** | One network flow (bidirectional connection summary) |
| **Licence** | MIT (generated by this repository) |

## Categories
| Category | Pattern modelled | Present in |
|---|---|---|
| `benign` | Diurnal traffic, mostly 443/80/53, 1.5 % large uploads (hard negatives) | all splits |
| `dos` | Short, high-packet SYN-heavy flows from 6 sources to 80/443 | train · val · test |
| `portscan` | 1–2 packet flows to random ports, RST-heavy, very high port diversity | train · val · test |
| `bruteforce` | Repeated mid-length flows to 22/3389/21 | train · val · test |
| `botnet` | Low-volume periodic beacons (≈90 s) from 2 internal hosts | train · val · test |
| `exfiltration` | Long, upload-heavy flows to 443 from one internal host | **test only** (novel) |

0.5 % of benign flows are label-flipped to simulate imperfect IDS labelling.

## Split
Time-aware: first 60 % of the capture → train, next 20 % → validation (threshold selection), last 20 % → test.
Campaigns never straddle a boundary.

## Real-data path — CIC-IDS2017
1. Obtain the *MachineLearningCVE* CSVs from the Canadian Institute for Cybersecurity (check the licence/terms).
2. Place them in `data/raw/` and set `source: cicids2017` in `configs/dataset.yaml`.
3. `ingestion/loaders.py::CICIDS_MAP` maps CIC columns to ThreatSense columns (duration µs → ms).
4. Known CIC-IDS2017 issues to handle: duplicate rows, `Infinity` values, label errors in some days,
   and near-duplicate flows across days — use day-level (source-aware) splits.

## Safe-use statement
Flow metadata analytics only. The project performs **no** network scanning, exploitation, credential
collection or traffic capture, and must not be presented as a production security control.
